### The fourth part: Using coding agents.
This is a key AI engineering skill and the ability for one to monitor, use it to make more and quick progress while building projects and designing platforms by making relevant choices like deciding workflows and also making the right tradoffs would save so much time and improve on productivity as well.
#### An observe professional workflow for building software with agents include:
- planning: this involves making sure to point out the necessary requirements for the project, the tradeoffs, understanding the available codebase, pointing out the architectural design, and also maintaining a workflow.
- execution: this is the stage where you build, test, and verify the project that the agent has just built, using the requirements and the test inputs the project would be using as well. This is having the agent build the software with automation and then later verifying with human tests to know if the build was done correctly according to your plan or not, and also making the necessary corrections as well.
- deployment and monitoring: This is the stage where you actually deploy or put the software on the web for proper and final tests before it is ready for use by real users. This is where final decisions are made and final corrections are also done on the product in question.

#### The key skills needed to use the above workflow are:
- Directing the workflow
- Enabling agent autonomy
- Reviewing the work
- Customizing the agent and its environment
- Coding agent foundations
Having good understanding on the above skills would make it more easier for one to user coding agents to design software.
